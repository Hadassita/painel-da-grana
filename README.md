# Painel da Grana

Organize o dinheiro do mês por semana. O ciclo começa no dia em que o dinheiro entra, uma parte fica guardada e para imprevistos, e o resto vira o dinheiro de cada semana (segunda a domingo). O que sobra passa para a semana seguinte.

- Funciona como app: dá para instalar na tela inicial no Android e no iPhone.
- Os dados ficam só no navegador de cada pessoa. Nada é enviado para servidor.
- Feito com HTML, CSS e JavaScript puro, sem dependências.

Para atualizar o site: edite `index.html` e mude a `VERSAO` em `sw.js`.
